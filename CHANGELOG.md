# Changelog

## v0.1.0-rc.1

- First separate public LLDP repository; protocol/runtime unchanged from the hardware-tested combined project.
- Neighbor sensors, enable switch, configurable own identity and explicitly calibrated UniFi physical-port mapping.
- Requires mvs90/esphome-usb-ethernet v0.1.0-rc.5 Layer-2 API; not arbitrary stock Ethernet backends.
- English/German usage guides, combined example, three sanitizer suites and pinned build CI.
